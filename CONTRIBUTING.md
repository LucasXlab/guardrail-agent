# Contributing

Use Python 3.11+ on macOS or Linux. Run `make dev`, then `make check` and `make demo`.
Add regression tests that exercise real simulator behavior with synthetic inputs.
Keep runtime code in the standard library and never add implicit networking,
credentials, telemetry, live orders, or claims of investment performance.

Describe the policy contract and any change to receipt trust precisely. Preserve
the existing tests' intent. Reports and screenshots must use synthetic data.
Do not post credentials or private audit exports in public issues.
